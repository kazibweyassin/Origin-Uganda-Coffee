Build a production-ready B2B Ugandan coffee export marketplace using Next.js, TypeScript, Tailwind CSS, Prisma and PostgreSQL.

The platform connects international coffee roasters, importers, distributors and manufacturers with Ugandan coffee supply.

Brand positioning:
"Source Ugandan Coffee Direct From Origin"

This is NOT a consumer ecommerce shop. It is a B2B sourcing and RFQ platform.

Core products:
1. Uganda Robusta
2. Uganda Arabica
3. Specialty / Traceable Microlots

Required pages:
- Homepage
- Coffee catalogue
- Individual coffee lot/product page
- Request a Quote
- Request a Sample
- About Uganda Coffee
- How It Works
- Contact
- Admin dashboard

Each coffee listing should support:
- Name
- Coffee type
- Variety
- Origin/region
- Grade
- Screen size
- Processing method
- Crop year
- Moisture
- Defects
- Cup profile
- Available quantity
- MOQ
- Packaging
- Certifications
- Traceability information
- FOB indicative price
- Status
- Images

RFQ form:
- Product
- Quantity in kg/MT
- Destination country
- Destination port
- Preferred Incoterm: FCA, FOB, CIP, CIF
- Packaging
- Sample required
- Buyer company
- Contact name
- Email
- WhatsApp/phone
- Website
- Buyer type
- Expected purchase frequency
- Notes

Do not implement online payment in V1.

Primary CTA:
"Request Current Quote"

Secondary CTA:
"Request Sample"

Design direction:
Premium international commodity trading platform.
Clean, institutional and modern.
Avoid generic African safari styling.
Use strong typography, generous spacing, data/specification tables and photography of Ugandan coffee, farms, processing and green coffee beans.

Homepage sections:
Hero
Live/available coffee lots
Why Uganda
How sourcing works
Quality & traceability
Shipping options
Buyer types served
FAQ
RFQ CTA

Create realistic seed data for 6 Ugandan coffee lots.

Build mobile-first and SEO-friendly.
Use server-side validation and a clean Prisma schema.
Start by creating the project architecture and homepage, then proceed page by page.
